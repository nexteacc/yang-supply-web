ChillDINVF.ttf is the unchanged ChillDIN v1.100 variable font (weight 325–700, normal width).
The YangGothicWeb WOFF files are subsets of ChillDINGothic v1.300 Std, generated with fontTools by scripts/prepare-chill-gothic.py. Glyph outlines are unchanged. The derived subset family is renamed Yang Supply Gothic Web to respect upstream reserved font names. The upstream Gothic font has one weight (500); CSS uses it as the regular face and browser synthesis provides heavier headings.

Subset 00 covers characters found in the site's source. Remaining characters are retained in disjoint unicode-range subsets, so new content can still display without rebuilding the fonts. Re-run the generator to optimize subset 00 for future copy changes. The CSS selects these fonts only for Chinese/English; Vietnamese retains its previous font stack.
