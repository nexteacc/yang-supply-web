## 共同规则
- 产品颜色名一律按老板提供的原图文件名（工厂命名），不按看图猜。
- 网站不放价格；产品报价和运费分开，客户可自选货代或由我们安排运输。网站要不要放价格由老板决定。对外只展示产品、80% 定金条款、交期、联系方式；费率和利润结构不对外。样品收费，破损补发。暂无新客优惠。
- 首页主图固定用 `sticker-dinh-da-co-lon-hop-qua.jpg`；不用带中文字的水钻图；不用实拍海星图。
- 任何对外邮件或消息都要老板确认后才发。
- 汇报顺序：要总结时，各成员按改动先后顺序向 Luid 汇报，Luid 写一份最终总结给老板，老板只看这一份。
